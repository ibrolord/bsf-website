# Annotate AI PR Plan

Mouse interactions were causing repeated JavaScript errors when users moved their mouse over the hero section. The root cause was a missing null check when accessing DOM element styles in the passive mouse event listener. The code was trying to manipulate the style property of a DOM element that doesn't exist, causing "Cannot read properties of null (reading 'style')" errors to spam the console on every mouse movement. Added proper null checking before DOM manipulation to prevent these crashes and improve user experience.

## Proposed files

- `src/utils/mouseEffects.js`: Added null checks before accessing DOM element styles and improved element selection
- `src/components/Hero.tsx`: Added ref and useEffect to ensure DOM elements exist before initializing mouse effects
- `src/components/HeroGradient.tsx`: Added data attribute for safer DOM selection and default opacity styling
- `public/index.html`: Added proper null checking and element existence validation in inline script

This PR contains a review plan only. Direct AI file writes are disabled unless ANNOTATE_AI_PR_WRITE_FILES=true is configured.
