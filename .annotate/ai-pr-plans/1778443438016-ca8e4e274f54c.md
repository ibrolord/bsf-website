# Annotate AI PR Plan

**What broke**: Network resource timing verification was failing to show Page resources when dashboard widget.js failed to load from Pages deployment and Google Analytics requests were blocked.

**Root cause**: Missing error handling for (1) annotate-dashboard widget.js loading failures due to deployment/network issues, and (2) Google Analytics request failures from ad blockers or privacy settings.

**What changed**: Added retry logic with exponential backoff for widget loading, graceful degradation for analytics failures, and enhanced network verification to distinguish critical vs non-critical requests.

## Proposed files

- `src/components/Hero.tsx`: Added error handling for dashboard widget loading and analytics tracking failures
- `src/utils/analytics.ts`: Added comprehensive error handling, timeout logic, and graceful degradation for Google Analytics failures
- `src/dashboard/widget-loader.js`: Implemented retry logic with exponential backoff and comprehensive error handling for dashboard widget loading
- `src/network/verification.ts`: Enhanced network verification to distinguish between critical and non-critical requests with proper error categorization

This PR contains a review plan only. Direct AI file writes are disabled unless ANNOTATE_AI_PR_WRITE_FILES=true is configured.
