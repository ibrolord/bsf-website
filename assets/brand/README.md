This folder stores Big Sister Foundation brand documentation tracked in the repo.

Structure:
- `final/` contains the canonical brand guide.
- `explorations/` contains earlier concept, recommendation, and supporting reference PDFs that informed the final guide.

Notes:
- `final/Brand_Guide.pdf` is the primary final reference.
- `final/Brand_Guide.pptx` is included as the editable source deck.
- Duplicate copies from the source folder were intentionally not imported.
- Generated archives and OS metadata files such as `.DS_Store` were intentionally excluded.
